### 20:55 2. Codex 샌드박스 orca CLI 재진단 — Claude (daily)
- 한 일: Codex 실행 환경이 Windows → 이 Rocky Linux 서버로 바뀐 것을 반영해 재진단. 샌드박스 안에서도 `orca` PATH·`ORCA_CLI_COMMAND`는 정상이지만, Orca 앱 소켓 접속이 막혀 `runtime_unavailable`. `workspace-write` + `network_access=true` 일 때만 접속 성공 (`writable_roots` 에 Orca 설정 디렉터리를 넣는 것만으로는 실패)
- 실행한 명령:
  ```bash
  codex sandbox -- sh -c 'command -v orca; orca orchestration run-list --json'
  codex sandbox -c sandbox_mode=workspace-write -- sh -c 'orca orchestration run-list --json'
  codex sandbox -c sandbox_mode=workspace-write -c sandbox_workspace_write.network_access=true -- sh -c 'orca orchestration run-list --json'
  codex sandbox -c sandbox_mode=workspace-write -c 'sandbox_workspace_write.writable_roots=["<ORCA_USER_DATA>"]' -- sh -c 'orca orchestration run-list --json'
  ```
- 결과·커밋: (이 항목의 커밋) — 기본(read-only)·workspace-write: 실패 / workspace-write + network_access: 성공 / writable_roots만: 실패. 설정 파일은 변경하지 않음
- 컨펌: 없음 (조회·로컬 시험만)
