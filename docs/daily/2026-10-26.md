### 09:36 실 AWS 사전 준비: 권한 확인·Route 53 호스팅 영역 — Claude (daily)
- 한 일: 사용자가 도메인을 직접 구입(`<DOMAIN>`). IAM 사용자 권한 확인 — `AdministratorAccess`, 구축에 필요한 19개 액션 시뮬레이션 전부 allowed. 서울 리전 한도 On-Demand vCPU 512, EIP 5 (필요 2). 사용자 승인 후 Route 53 퍼블릭 호스팅 영역 생성, NS 4개를 사용자에게 전달(등록 업체에서 네임서버 변경). `.env` 를 `.env.example` 에서 만들어 `AWS_ACCOUNT_ID`·`DOMAIN_NAME`·`ROUTE53_HOSTED_ZONE_ID` 기입(git ignore 확인, 커밋 안 함)
- 실행한 명령:
  ```bash
  aws iam list-attached-user-policies --user-name <IAM_USER>
  aws iam simulate-principal-policy --policy-source-arn <USER_ARN> --action-names route53:CreateHostedZone acm:RequestCertificate ec2:CreateVpc eks:CreateCluster ...
  aws service-quotas get-service-quota --service-code ec2 --quota-code L-1216C47A   # On-Demand vCPU
  aws service-quotas get-service-quota --service-code ec2 --quota-code L-0263D0A3   # EIP
  aws route53 create-hosted-zone --name <DOMAIN> --caller-reference <DOMAIN_PREFIX>-$(date +%s)
  ```
- 결과·커밋: (이 항목의 커밋) — 호스팅 영역 1개 생성(월 $0.50). 되돌리기: `aws route53 delete-hosted-zone --id <ZONE_ID>`
